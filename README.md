## 📖 About This Repository

This repository is a **living document** of my Python learning journey. I add something new almost **every day**  from simple beginner scripts to classic AI algorithms. It's structured so **anyone can learn Python** by reading the code, running the programs, and building on top of them.

> 💡 **For learners:** each script is self-contained and beginner-friendly. Read it, run it, break it, and fix it  that's how you learn!

## 🎯 Suggested Learning Path

> Follow this order to build concepts progressively. Each step takes a few minutes and 100% of the code is read-only exploration  or better yet, try modifying it!

### 🔰 Step 1  The Basics

| File | What you'll learn |
|------|------------------|
| [`Basics/Bigenner.py`](Basics/Bigenner.py) | `input()` & `print()`, type casting, conditionals, loops, f-strings |
| [`Basics/task1.py`](Basics/task1.py) | Arithmetic, variables, chained `if/elif/else` |
| [`Basics/task2.py`](Basics/task2.py) | Lists, `for` loops, `sum()` / `max()` / `min()` |
| [`Basics/task3.py`](Basics/task3.py) | Dictionaries, file I/O (`open` / `write` / `read`) |
| [`Basics/task4.py`](Basics/task4.py) | **Object-Oriented Programming**  classes, `__init__`, `self`, methods |

### 🎮 Step 2  Build Games (learn by having fun)

| File | What you'll learn |
|------|------------------|
| [`Basics/Game No.1 Quize .py`](Basics/Game%20No.1%20Quize%20.py) | String methods, score tracking |
| [`Basics/Game No.2 Guessing .py`](Basics/Game%20No.2%20Guessing%20.py) | `while` loops, `random`, input validation |
| [`Basics/Game No.3 R.P.S .py`](Basics/Game%20No.3%20R.P.S%20.py) | Lists, game logic, break conditions |
| [`Basics/Game No.4 Adventure.py`](Basics/Game%20No.4%20Adventure.py) | Nested conditionals, branching story logic |

### 🧠 Step 3  AI Algorithms (the fun part!)

| File | Algorithm | What you'll learn |
|------|-----------|------------------|
| [`AI  Algorithms/minmax.py`](AI%20%20Algorithms/minmax.py) | Minimax | Recursion, decision trees, max/min players |
| [`AI  Algorithms/alphabeta.py`](AI%20%20Algorithms/alphabeta.py) | Alpha-Beta Pruning | Optimizing minimax, tree traversal |
| [`AI  Algorithms/astar.py`](AI%20%20Algorithms/astar.py) | A* Search | Heuristics `f(n) = g(n) + h(n)`, priority queues (`heapq`) |
| [`AI  Algorithms/mazeSolver.py`](AI%20%20Algorithms/mazeSolver.py) | BFS | Graphs, `deque`, path reconstruction |
| [`AI  Algorithms/genetic.py`](AI%20%20Algorithms/genetic.py) | Genetic Algorithm | Fitness, selection, crossover, mutation (8-Queens) |
| [`AI  Algorithms/GeneticNQueen.py`](AI%20%20Algorithms/GeneticNQueen.py) | Genetic Algorithm | N-Queens with visual board rendering |

## ✍️ How to Contribute to Your Own Learning

1. **Run** every script first  don't just read it.
2. **Modify** it after you understand it (change ranges, add features).
3. **Redo** it from memory the next day  spaced repetition builds skill.
4. **Write your own version** in a separate file to prove you've learned it.

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/your-username/Python.git
cd Python

# Run any script
python "Basics/task1.py"
python "Basics/Game No.2 Guessing .py"
python "AI  Algorithms/mazeSolver.py"
```

> 📌 **Note:** some scripts (games, minmax, maze solver) are **interactive**  they will ask for your input when run.
